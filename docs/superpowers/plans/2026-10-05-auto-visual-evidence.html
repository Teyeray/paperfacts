01

交付一个能自动跑完的补证流程

日常无需人工选区域、点击读图或逐条确认。无法确定时，系统留下原因并继续。

GOAL

更少遗漏，更少错误归属

把“两路有分歧”与“独立发现但尚未覆盖”的内容自动送去看原图。每条输出都能回到论文中的页、区域和可见依据。

三种读取方式来自同一篇论文，增加的是解析核对依据，不是三份独立科学证据。

ARCHITECTURE

一个辅助步骤，复用已有组件

复用 PDF 渲染、裁图、视觉客户端、缓存和单位规范化。先用冻结输入离线评估；验收后接入现有 workflow.run_document。

Python 3.13 · pypdfium2 / Pillow · 现有 OpenAI-compatible 服务 · pytest / ruff。

第一版范围：自动选候选、读完整事实、输出旁路报告；真实验收通过后接入常规任务。自动采纳作为独立关口，样例不足时保持旁路模式。

本轮优先解决

  • 表格数值冲突、单路缺失、单位/条件混淆。
  • 独立文字扫描发现的相关图表页与部分共同遗漏。
  • 模型失败、预算耗尽时，已有双路结果仍可使用。

暂缓建设

  • 第三个全文解析 Backend、三路多数投票。
  • 通用子图分割模型、新数据库、新队列。
  • 专门的三路 UI、图谱、跨论文关系系统。
  • 曲线估读自动进入精确事实主表。

C 的输入准备可参考 A/B 的位置，但读取结果不以 A/B 答案为提示。独立发现的页面允许出现新的样品候选，第一版不据此自动建主表行。

规则示例 · 静态演示，不调用模型

自动选中同一样品的电阻率存在数值或单位倍率冲突。

独立读取C 读取完整表头、样品行、原始数值和单位。第一版输出对照建议；满足采纳关口与原因白名单后，才允许替换该冲突决策。

独立发现原 PDF 的 Table 标题或相关关键词指向一个未被 A/B 对应证据覆盖的页面。

补充候选C 在整页中寻找字段与样品，输出新增事实候选。新样品、纯曲线估读和覆盖不确定仍留在补证报告中。

有限重试只有像素不足且能确定目标区域时，允许一次局部放大。

自动结束仍读不清、缺另一页表头或归属不唯一 → 输出未决原因。不会循环询问模型，也不会阻塞整篇完成。

两类目标同等重要：首轮每篇四个去重候选，分配为两个风险复核名额＋两个独立发现名额；一类不足时将剩余名额借给另一类。先合并重复区域，保留全部来源与原因，同一区域只占一个候选名额；初读去重，仍允许一次必要放大。某页已有 A/B 引用不表示该页的其他表、列或条件已覆盖。
两类候选分别排序与分配，不再按 P1→P4 全局截取前四项。
类别 / 顺序触发条件第一版处理
风险 · P1数值/单位/条件冲突；候选无法可靠定位读取完整上下文；不能定位到页则记录未决，不占可读候选名额。
风险 · P2只有一路有值复核已有出处，同时检查样品与字段归属。
独立 · P3独立发现的相关页；无可用文字层的页整页读取；不因同页已有 A/B 引用而排除，扫描页不宣称完整覆盖。
风险 · P4两路一致，但有倍率表头、脚注或复杂条件风险输出核对结果；第一版不覆盖原本一致的主表值。

六个任务，按验收关口推进

任务内先写能暴露错误的测试，再做最小实现。下列均为计划项，展开可查看文件、步骤与验收。

T0 输入→T1 候选→T2 读图→T3 评估→净增益关口→T4 接入→采纳关口→T5 采纳
T0
锁定实际输入与基线
产出：可重放的输入清单、数据位置、论文划分和运行上限。
修改：eval/README.md；复用：storage.py、eval/gold/*.json、profiles/tco.json。运行产物仅写忽略目录。
  • 核对 HEAD、工作区、有效 data_root 和现有服务配置；不把密钥或完整私有配置写入报告。用户已确认沿用现有目录与服务。
  • 匹配 11 份 gold 对应 PDF 的 SHA；记录缺失、版本不同、无 A/B 缓存的项。manifest 分列现有 document_id / 文档身份 SHA、实际读取 PDF 的字节 SHA，以及已有 parts 的摘要与页区间；正文＋SI 的身份不必等于合并文件 SHA。通过现有 storage 解析文档，裁图沿用其目录，不按文件新摘要另建文档。不得隐式重跑全链。
  • 固定 A/B artifacts、facts、comparison 和最终 dataset 的明确路径与内容摘要，记录 profile、代码、gold 版本；G1 对照冻结 A/B 完整事实，G2 对照冻结主表，不依赖“最新文件”选择。
  • 逐篇记录历史评估、prompt 调整和 C 规则设计的使用史。11 篇齐全时“按 doc_id 排序前 6 / 后 5”仅作初始划分；在调 C 的 prompt 前依据使用史与案例覆盖冻结整篇划分。只有未参与 C 规则设计的论文才可作为 C 留出，不称为整个系统未见论文；不足时记录缺项，不反复调留出。
  • 冻结评估页面与事实范围；对原图登记范围内的明确印刷事实、条件/状态和排除理由，不能只给旧 gold 补标签。逐拟采纳字段与证据类型统计有效纠错、共同补漏机会及独立论文数；未覆盖类别和零机会范围单列，不能以论文总数或正确单元格总数代替。
  • 先在 eval 文档规定 output/visual-evidence/YYYY-MM-DD-run-id/ 的用途与生命周期，再由 storage 定义路径。只存运行报告、私有裁图与响应引用，不清理历史。
  • 固定候选与重试上限，记录实际请求与 token；用户确认暂不考虑金额预算。数据不齐可继续合成测试，真实评估停在输入关口。
完成条件待评估文档的原 PDF、身份、冻结 A/B 与主表、gold 版本、使用史、划分及有效机会数均可核验；缺项明确列出。某范围缺少有效留出机会时限制该范围的真实验收，不阻塞已有输入的开发和回归。

接口边界（拟新增）

read_native_pages(pdf_path) → NativePage[] 只返回文字层与可定位的文字坐标；select_candidates(pages, artifacts, lanes, comparison, profile, limit) → CandidateSelection 返回候选、跳过项与覆盖说明。

  • 先测：A/B 为空但 PDF 存在相关表题仍产生候选；同页已引用一张表但另一表未覆盖仍进入独立候选；风险项超过四个时独立发现仍保留两个名额；两类重复区域初读去重且不占双份名额；一类不足可借额；两路一致的复杂单位表仍可触发。
  • 所有 PDFium 调用进入 pdf.py 的现有进程锁。页码统一 0-based，坐标统一 NormalizedBBox；旋转页/非零 CropBox 要验证定位。
  • 风险类内部按 P1→P2→P4 排序，独立发现为 P3；同级按页号与坐标排序。先按区域去重，再从风险/独立列表交替取尚未入选项，首轮各分配两个名额；同一区域保留双来源但只计一次，名额记在选中它的类别。某类不足才借额。其他 limit 按风险 floor(limit/2)、独立剩余名额分配，实验内固定。候选保存页/框、全部原因、字段及可选样品上下文。
  • 独立候选默认整页，不依据图注位置猜完整图边界；A/B 候选有完整区域时才裁图。同一整页已入选时合并内部小框的触发原因并保留原框供必要放大；几何覆盖不等于缩图后仍可读，读不清时沿用 T2 的一次放大或未决结果。
  • 使用 profile 现有关键词；通用 Figure/Table 标记可做轻量规则。语义表格检测和子图切分暂不进入第一版。
  • 无文字层、预算截断、无出处页分别保留原因；“无候选”不能直接显示为“全文无遗漏”。
完成条件自动选取不依赖用户点击；独立来源不依赖 A/B 样品；选择顺序、合并和覆盖说明可用确定性测试复现。文字提取只负责定位，不宣称完成版面理解。

接口边界（拟新增）

read_candidate(candidate, document, profile, crop_store, client) → EvidenceResult。结果含完整原始观察、outcome、reason 和程序绑定的出处。一个区域可返回多条事实；不增加第三种 Backend。

  • 先测提示词不含 A/B 候选答案；针对独立发现不限制为旧样品清单。用“同数字在另一行”“倍率单位”“脚注条件”验证归属不能由数字命中替代。
  • C 的提示词继承 profile 的 sample_definition、field_scope、论文级/样品级规则及已确定的 article_type 提示；区分本文研究对象、购买基底、其他器件层和引用文献结果。读取原图的独立性不等于放弃同一领域定义。
  • 观察记录 scope（paper/sample）、entity、样品原名、字段、value_raw、unit_raw、condition、condition_status（stated / not_stated / unclear），以及可见行头/列头/图例文字。保留范围、上下界、近似符号，不转成精确标量；单位换算交给现有 UnitRegistry。
  • 样品原名到已有行的匹配复用 entity＋sample_key 的唯一匹配及既有 A/B 行映射；无唯一匹配则留作未归属观察，不通过模糊名称相似度或数值接近认领。论文级事实不挂到样品上。先测其他器件层、文献引用、同名跨实体、条件未注明与无法判断的区分。
  • document_id、实际 PDF 字节 SHA、页码、bbox、实际 PNG SHA 与已有 parts 页区间由程序绑定，身份规则见 T0。模型给出的行列说明属于待核实观察，不视为独立确定性证明。
  • 复用 CropStore 前将 max_pixels 纳入裁图身份；旧裁图不删除、不误复用。不同参数、旋转页与多页引用分别测试。
  • 严格解析 JSON 和字段类型。坏 JSON、截断、缺图、网络失败进入未决/错误；不使用 parse_reading 的自由文本兜底确认事实，也不直接用 adjudicate 采纳。
  • 初次图像太小且能确定局部区域时最多放大一次；跨页缺上下文先弃权，不只检查第一页就确认整条事实。
  • 复用 complete_vision 的缓存、全局并发和离线拒绝。报告记录图片、prompt 与模型配置摘要；缓存命中仍需重新执行严格解析。
完成条件任意结果可回到实际读取的原图；请求内容不泄漏 A/B 答案；单区域失败不丢失其他结果。假客户端只证明这些工程行为，不证明视觉准确率。

  • 先测缺 A/B 输入立即报缺项、不启动解析器；一次读图失败不影响已完成记录；重复运行用缓存，离线模式网络请求为零。

  • 在开发集同时冻结候选规则、prompt，以及拟采纳的字段、证据类型与规则；再一次性使用留出集评分 G1，并保存离线采纳回放供 G2。根据留出错误调参后，原留出结果降为开发证据，需新的未见论文再验收。
  • 按文档＋scope/entity/对象＋字段＋条件状态/测量状态建立人工核验的事实标识，一对一匹配、重复观察只计一次，不能用被评估的数值反过来决定样品归属。先测同样的 77% 分别对应平均波段与单点波长、同事实多处引用、错误样品与未标注事实。
  • G1 分别计算纠错与共同补漏净收益，按下节评分契约归类，不把重复确认算新增。G2 将冻结规则回放到冻结主表，统计真正改变的单元格、错误采纳与正确值回退；两者不能共用一个“增益”总数。分别报告候选召回、完整元组正确率、弃权、实际触发/采纳数、独立论文数、调用与耗时。
  • 现有 figure_only 在旧评分中属于软匹配，另报明确印刷值与曲线估读结果。禁止把旁路补证数量当成主表召回率提升。
完成条件 · 关口 G1在有效 C 留出集上，纠错与共同补漏两个目标分别有正净收益，错误建议与资源开销公开；一侧收益不能抵消另一侧无收益或负收益。这不表示主表已经提升。零有效机会属于证据不足，不算通过；未通过则保留实验结果，不进入 T4。

04

把“能运行”和“值得运行”分开验收

不用三路一致率代替准确率，也不把一次模型成功响应当成科学事实确认。

候选召回

被选区域覆盖的范围内事实 / 原图独立核验的范围内事实。按文字层、扫描页、图表分别报告；未穷尽标注时仅称“已标注事实召回”。

事实正确

对象、字段、值、单位、条件/状态均正确的明确观察 / 已完成真值核验的明确观察；一对一去重，并另报待核验数量与弃权率。

实际净收益

纠错、共同补漏分别算正确新增减错误建议；主表回放另算实际改善减新错误。重复确认不增加收益。

逐事实评分契约：事实身份不依赖模型输出的数值；同一事实多处出现只计一次。
评分对象基线与计数规则不能计作收益
G1 · 纠错冻结 A/B 在该事实已有候选但存在错误或未解决冲突；C 给出完整、正确的纠正建议计一次，错误建议计一次负项。仅再次确认已有正确事实；仅数字相同但样品、单位或条件不同。
G1 · 共同补漏该范围内事实在冻结 A/B 均缺失；C 找回完整正确事实计一次，新增错误事实计一次负项。与纠错按基线是否已有候选互斥归类。重复发现同一事实、范围外观察、未标注而尚待核验的观察。
G2 · 主表采纳将冻结规则作用于冻结 dataset；错误/遗漏单元格变正确计改善，错误采纳及原正确值回退计错误。保留逐单元格前后值与依据。留在旁路的观察、没有改变主表的确认，以及零实际触发范围的“零错误”。
条件与标注范围原图核验表固定对象、字段、条件状态/测量状态与真值；stated、not_stated、unclear 分开。只在完成标注的范围内计算确定指标。把平均波段与单点波长的相同 77% 合成一个事实；把不完整 gold 当全文事实清单。
关口必须有的证据不通过时
工程通过候选确定性；坐标/图片身份一致；坏响应不确认；离线零网络；关闭零额外调用。修复对应边界，不启动真实评价。
G1 · 值得接入有使用史记录的 C 留出集上，纠错与共同补漏分别净收益为正；有效机会数、待核验项、请求数、耗时、错误建议透明。一侧无收益则不通过；零有效机会则证据不足。保留实验报告，停止集成，不以另一侧收益抵消。
G2 · 可以采纳逐预定字段/证据范围，有真实触发采纳且无错误采纳或正确值回退，主表净收益为正；报告采纳数与独立论文数。未覆盖或失败的范围维持旁路，不根据留出表现临时改规则筛选通过项。

05

自动化可以保守，结果必须诚实

完全无人值守的交付物可以同时包含采用值、补充观察和未决项。

经 G2 验收后，允许自动采纳

  • 已有样品上的明确遗漏或获准数值/单位冲突。
  • 原图有明确印刷数值。
  • 样品、字段、单位和条件对应清楚。
  • 通过现有规范化与范围校验。
  • 字段、证据类型与原决策原因均在批准范围。
  • 保留原始 A/B 值与采纳依据。

自动记录未决或补充观察

  • 曲线估读、图例含糊、样品无法唯一匹配。
  • 跨页缺上下文，或文字过小仍不可辨。
  • 只能证明同一个数字出现在别处。
  • 第三路与已一致的 A/B 发生冲突。
  • 独立发现了新的样品或未知条件。
  • 预算耗尽、请求失败、覆盖无法确定。
采纳原因白名单；先检查样品身份、提问状态和测量语义，再判断原单元格原因。
原决策原因 / 情形第一版处理必要边界
missing · 明确遗漏可进入采纳判断。已有样品唯一匹配；A/B 提问已完成；C 的完整事实、字段与证据类型通过 G2。
conflict · 获准数值/单位冲突可进入采纳判断。同一对象和测量条件已确定，C 能给出完整印刷事实；不是用第三路绕过样品或条件歧义。
unanswered / ambiguous / unreviewed维持未决，C 仅报告观察。提问失败、样品匹配歧义、缺比较覆盖不能仅凭主表为空而采纳。
multiple_conditions / multiple_values / non_scalar维持原决策，C 仅报告观察。不任意选择条件或多个值；范围、上下界和近似符号原样保留，不改成精确标量。
其他原因、A/B 原本一致默认不采纳。扩展原因需先在开发集冻结并验收；不临时根据留出结果放行。单路已有正确值的再次确认不计增益。

条件状态为 unclear 时不采纳；not_stated 仅在字段无需条件且不存在多状态歧义时允许。真实条件/状态冲突先保留旁路，不因数值可解析而强行消解。

不能用“两票对一票”决定事实。三路可能共享模型错误，也可能对同一表头产生同样误读。模型自报高置信度和数字字符串命中，均不能单独触发自动采纳。
