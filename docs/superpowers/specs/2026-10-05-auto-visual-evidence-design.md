# PaperFacts 自动原图补证设计

日期：2026-10-05。状态：方案；方向已确认，产品代码和真实模型评估尚未实施。
本设计替代 2026-10-02 手动视觉复核设计；[行动方案（HTML）](../plans/2026-10-05-auto-visual-evidence.html) 是任务与验收的唯一详细清单。
审查基线：`main`，`e126e1d1aeea4046511739e1296be3ae06201aa2`；实施前重新核对。

## 目标与已确认输入

保留 MinerU / PaddleOCR-VL 的双路全文抽取，用一个自动选择候选、读取原始页面、输出完整事实的辅助步骤，识别冲突和部分共同遗漏。日常运行无需人工选择区域或逐条确认；无法确定的项目可自动留为未决。

- 用户确认首轮沿用现有 TCO 领域与样例、现有数据目录、项目现有模型服务。
- 用户确认暂不考虑金额预算：金额上限与价格核算不作为方案前置关口；仍保留请求/重试上限和实际用量记录。
- 配置文件的 `data_root` 为 `data`，实际入口可能存在环境覆盖；当前 checkout 未发现 PDF。T0 必须核对有效路径、PDF SHA 和既有 A/B 产物，不能把存在 gold 等同于存在可运行输入。
- 用户本次授权制作 HTML 行动方案，不授权产品实现、真实模型调用、发布或推送。
- C 是同一论文的额外读取方式，不是独立科学来源；不采用三票多数决。

## 最小架构

PDF → A/B → compare；同时从原 PDF 文字层独立找相关页。候选选择合并两种来源：A/B 风险位置与独立发现的相关页。C 用原图独立抽取原始事实，结果在旁路报告中与 A/B 对照。真实验收通过后，把同一补证函数接到 `workflow.run_document` 的 compare 后、export 前。

- 第一版原生定位做到页级。精确、完整的 A/B 引用可复用已有区域裁图；独立候选默认整页，避免先造版面分割引擎。
- 候选优先级：数值/单位/条件冲突和无出处 → 单路缺失 → 独立未覆盖相关页 → 一致但有复杂表头等风险。同页整页图覆盖其内部小框时合并请求；保留所有触发原因。
- 独立发现不得以 A/B 已找到的样品或 SourceBlock 为前提。文字层不可用的页作为扫描页候选，受同一预算限制。未处理、超限或无法判断覆盖的页必须记录，不能声明全文核验完成。
- 给模型原图和 profile 的字段定义。针对已有事实可给样品标识；独立发现不限制为既有样品列表。不给 A/B 数值、单位答案、比较结论或解析文本。
- 输出样品原名、字段、原始值、原始单位、条件、可见行列/图例依据；页码、裁图框、图片 SHA 由程序绑定，不能由模型虚构。单位转换复用 profile 的 UnitRegistry。
- 结果最少包含 outcome、reason、原始观察和出处。数字出现匹配只作诊断；不能使用现有 `validate.adjudicate` 直接确认事实。
- 跨页缺上下文、样品歧义、曲线估读、结构损坏均不自动采纳。近似曲线读数沿用既有 figures 的独立语义。

## 实施范围与资源边界

先复用 pdf.py、CropStore、VisionClient、storage 和现有规范化；最多增加一个扁平的 visual_evidence.py 模块和一个离线实验入口。先不引入 pypdf/PyMuPDF/分割模型，不扩充 Backend，不新增队列、数据库、独立 Web job 或专门的三路界面。

首轮实验建议每篇最多 4 个去重候选、每候选最多 2 次逻辑读图（正常读取＋一次必要放大）；客户端每次请求最多重试 1 次（retry_attempts=2 表示总尝试 2 次），每策略最坏每篇 16 次 HTTP 请求、11 篇 176 次，两种 C 策略独立执行最坏 352 次；不能假设缓存交集一定存在。这是运行边界，不是金额预算；按用户回复不设金额审批关口。候选/请求数、token、耗时与超限项进入报告，扩充候选覆盖时重新固定实验参数。C 串行运行并遵守现有全局模型并发控制。无需新预算服务。

复用请求级缓存；修复 crop 文件身份缺少 max_pixels 的问题。报告记录 PDF SHA、实际图片 SHA、A/B 输入摘要、profile、模型/提示词/参数、代码与 gold 版本。旧实验不自动删除；纯读取/导出零模型调用。

## 验收与接入

先冻结输入离线运行 C，不调用完整 run_document 隐式重跑 A/B。按整篇论文划分开发/留出集，覆盖冲突、同错、共同漏检、正确对照、复杂单位/条件和不可判定案例。在开发集同时冻结候选规则、prompt 和拟采纳字段/证据类型及规则，之后一次性使用留出集评估旁路净增益 G1 与离线采纳回放 G2。根据留出错误修改规则后，原留出只能作为开发证据，需新的未见论文再验收。现有 gold 不足以验证区域覆盖与归属的部分须先对原 PDF 核验标注；这是开发验收，不是日常逐篇人工操作。

工程验收要求：确定性候选、原图可追溯、严格解析、失败隔离、缓存正确、离线零网络、预算有界。真实验收分别报告候选召回、完整元组正确率、纠错/误改、找回遗漏、弃权率、请求数和耗时；不改变 eval/score.py 的 figure_only 旧语义。

先验收旁路净增益，再接入自动补证。自动采纳单独验收，只允许经验证的字段、明确印刷数值、唯一匹配到已有样品且单位/条件完整的结果；两路原本一致的值第一版不覆盖，独立发现的新样品不自动建行，曲线估读不填主表。无足够留出证据就保持自动旁路，无人值守照常完成。

生产接入默认关闭新的自动补证设置，不能因旧配置 vlm.enabled / fill_blanks 为 true 而突然调用或填表。启用后普通运行自动执行；关闭后恢复现有双路行为。采用单一 workflow 入口，保留 A/B 数据及二路 compare 含义；将获准采纳记录作为带来源的显式最终决策，相关派生结果与缓存指纹同步更新。
